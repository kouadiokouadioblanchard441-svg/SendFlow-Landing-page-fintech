---
name: Landing page appearance approval
description: The user's standing constraint for visual changes to the SendFlow landing page.
---

Keep the SendFlow landing page's existing appearance unchanged unless the user explicitly asks for visual edits.

**Why:** the user said the landing page must remain as it was and objected to visual changes they had not requested.

**How to apply:** security reviews, reliability work, and backend changes must not alter the landing page's visual presentation without explicit approval.
